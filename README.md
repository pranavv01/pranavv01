## Selected Work

### [Divyanayan - Reading Assistance App](https://github.com/pranavv01/Reading-Assistance-App)

An Android reading assistant for visually impaired users, built with Java, CameraX, OCR, and text-to-speech. The system combines Google ML Kit and Tesseract for multilingual recognition, supports gesture-based navigation, and uses UDP/TCP communication for embedded-device image transfer.

`Android` `Java` `OCR` `Text-to-Speech` `Firebase` `Computer Vision`

### RAG Document Retrieval Pipeline

A privacy-focused, local retrieval-augmented generation pipeline for document question answering. It uses document chunking, sentence-transformer embeddings, vector search, and RetrievalQA to produce context-grounded responses without sending source documents to hosted services.

`Python` `LangChain` `Llama 3` `Ollama` `FAISS` `ChromaDB` `Hugging Face`

### [Employee Registration REST API](https://github.com/pranavv01/Employee_Registration)

A layered Spring Boot service implementing CRUD workflows with clear controller, service, and persistence boundaries. PostgreSQL and Spring Data JPA provide durable storage, with endpoints tested through Postman.

`Java` `Spring Boot` `Hibernate` `PostgreSQL` `Maven` `REST`
